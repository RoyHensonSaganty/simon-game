# Simon Game 🎮

An interactive **Simon Memory Game** built using **HTML, CSS, JavaScript, and jQuery**. The game challenges players to remember and repeat an increasing sequence of colors and sounds.

---

## 🎯 Game Rules

1. Press any key to start the game.
2. Watch the color that flashes.
3. Click the same color to repeat the pattern.
4. Each level adds a new color to the sequence.
5. Repeat the full sequence correctly to advance.
6. Clicking the wrong color ends the game.
7. Press any key to restart the game.

---

## 🚀 Features

* Interactive color animations
* Sound effects for each button
* Increasing difficulty levels
* Game over detection and restart
